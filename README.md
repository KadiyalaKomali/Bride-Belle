# Bride Belle 👰🤵

An Android app developed for bridal and groom accessories shopping.

## 🛠 Technologies
- Java (Android)
- Firebase (Authentication/Database)
- XML for UI

## 🏆 Achievements
- 🥇 First Prize @ KPCode4u Android Hackathon

## 💡 Features
- Product listing
- User Authentication
- Shopping Cart
- Order tracking (future)
