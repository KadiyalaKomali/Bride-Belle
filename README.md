#  Bride Belle - Android App

Bride Belle is a shopping app tailored for brides and grooms to find accessories and essentials with ease.

##  Features
1. Splash Screen
2. Login Page
3. Home Page
4. Product Browsing
5. Cart Page
6. Order Confirmation
7. Profile and Order History

##  Technologies Used
- Java (Android)
- XML

##  Future Scope
- Flutter-based version
1. Admin dashboard
2. Order tracking and payment integration
3. Integrate AI-based recommendations.
4. Add AR features for virtual try-ons.
5. Implement multi-language support.
6. Enable live chat support.
